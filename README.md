# AutoSeminar-Agent：基于自主智能体的沉浸式研讨课教具套件生成器
一键将静态教学案例素材转化为“开箱即用”的翻转课堂研讨包与本地交互式沙盘教具。

## 1. 项目背景与痛点
在大学各类通识课、公共选修课与跨学科研讨课（Seminar）中，翻转课堂和小组案例辩论是常见的教学形式，但在实际落地中存在两大痛点：
1. 备课成本高：教师或主讲小组需要花费大量时间阅读长篇素材，并手动拆解争议焦点、分配角色立场、制定讨论时间表。
2. 课堂互动枯燥：传统的汇报通常停留在“静态 PPT 朗读”，台下同学参与感低；而第三方互动投票工具配置繁琐、功能割裂，难以针对具体案例深度定制互动逻辑。

### 为什么必须使用 AI Agent？
普通对话式大模型（如 ChatGPT）只能在聊天框中输出静态长文本，用户仍需手动排版与二次制作。
本项目利用具备本地环境操作权限与工具调用能力的自主智能体（Antigravity），扮演一名“数字化教学设计师”：用户仅需提供一份原始案例资料，Agent 自主在本地完成材料研读、方案规划、文件编写与前端教具代码构建，端到端交付整套教学工具包。

## 2. 系统核心工作流
[ 输入：原始案例资料 ] (例如：科技伦理新闻、法学判例、管理学案例)
          │
         ▼
[ Antigravity 自主执行闭环 ]
   ├─ 1. 环境感知 (Perception)   ：读取本地素材文件，提炼核心争议与认知目标
   ├─ 2. 教学规划 (Planning)     ：设计 45 分钟研讨流程与多方对抗角色卡
   ├─ 3. 工具执行 (Tool Action)  ：本地创建工程目录结构与 Markdown 教学文档
   ├─ 4. 教具构建 (Code Action)  ：自动编写零依赖的单文件交互网页 (HTML+JS)
   └─ 5. 校验交付 (Verification) ：在工作区校验文件完整性，交付开箱即用套件
          │
         ▼
[ 产出：完整的 seminar_pack/ 教学套件包 ]

## 3. 产物目录结构与内容说明
Agent 自主执行完毕后，将在本地工作区生成如下目录：

seminar_pack/
├── README_TEACHER.md           # 教师/主讲人导读手册（45分钟课堂节奏、破冰策略与控场指南）
├── case_background.md              # 案例背景与核心争议点梳理（事实陈述、各方诉求、核心两难）
├── roles/                                         # 分组角色扮演卡（用于课堂分组辩论）
        ├── role_A_developer.md      # 角色卡 A：技术开发者/企业方（核心诉求、辩护策略、预置软肋）
        ├── role_B_victim.md            # 角色卡 B：受害群体/公民代表（核心诉求、伦理指控、预置软肋）
        └── role_C_regulator.md       # 角色卡 C：法律与监管者（评判标准、公共利益考量）
└── interactive_poll.html               # 核心亮点：单文件离线交互式教具（双击即可在浏览器运行）

### 核心亮点：interactive_poll.html 交互式教具
1. 零依赖运行：纯原生 HTML + CSS + JavaScript 构建，无需安装任何环境，双击浏览器即开即用。

2. 课堂投屏互动：
立场倾向即时投票：大屏幕实时展示全班观点分布与动态柱状图动画。
责任天平调节滑块：允许同学上台拖动滑块，分配不同主体的责任占比（如：企业 40% vs 个人 60%），直观展示多元立场的冲突与博弈。
